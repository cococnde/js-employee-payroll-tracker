# js-employee-payroll-tracker

An application that allows a payroll manager input employee data such as first name, last name, and salary and view the information in a table. The application can also calucate the average salary and select an employee at random.

## Description

This application is designed to help payroll managers efficiently manage employee data. Key features include:
- Adding new employees with their first name, last name, and salary.
- Displaying all employee information in a tabular format.
- Calculating and displaying the average salary of all employees.
- Selecting and highlighting a random employee from the list.

The application is built using JavaScript, HTML, and CSS, ensuring a responsive and user-friendly interface.
## Usage

To use this application:
1. Clone the repository: `git clone git@github.com:cococnde/js-employee-payroll-tracker.git`
2. Navigate to the project directory: `cd js-employee-payroll-tracker`
3. Open `index.html` in your web browser.
4. Use the form to add employee details and view the information in the table.
5. Click on the "Calculate Average Salary" button to see the average salary.
6. Click on the "Select Random Employee" button to highlight a random employee.
